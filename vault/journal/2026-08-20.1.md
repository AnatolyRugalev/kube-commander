# 2026-08-20 — STORY-06j-2: scrolling past the last log line re-arms follow

- Agent: claude-opus (do-rewrite-leg)
- Milestone: M5 (UX-validation line, D268)
- Did: Folded in `2026-08-15-logs-scroll-past-end-resumes-follow.md`, the S03
  high-priority finding that scrolling back down to the bottom leaves the reader
  parked at the end of a *silently frozen* stream — only `G` re-armed following,
  and a reader already sitting on the newest line has no reason to press it.
  Second slice of STORY-06j. Every downward navigation in the logs view
  (`nav.down`, `nav.halfPageDown`, `nav.pageDown`) now routes through a new
  `scrollDown`, which re-arms following iff `atNewest()` — paused, not selecting,
  a non-empty body, and the cursor already on the last shown line — and otherwise
  just moves the cursor as before. So **landing on the newest line is still
  browsing** (the frozen snapshot a reader scrolled down to read stays frozen, and
  a page-down that overshoots the end from above only lands there), while the
  **next** press — the one vim would make a no-op — is the unambiguous "and keep
  going", which in a pager over a live stream can only mean rejoin it: it does
  exactly what `nav.bottom` does (`following = true` + `syncContent`, which pins
  the cursor to the newest line). Visual mode is excluded: a downward key there
  extends the selection, and re-arming would hand its moving end to the stream —
  the same reason `G` does not resume following mid-selection (D242 pt 5).
  `TestDownwardScrollDoesNotResumeFollowing`, which pinned D147's downward half,
  is replaced by the pair that pins the new two-step rule plus a visual-mode
  guard. README's logs paragraph names the gesture; the feedback file is deleted
  (D69).
- Decisions: **D281** — a downward scroll *past* the newest log line re-arms
  following (the gesture is the press after the one that lands; every downward nav
  says it, and only when the move is a no-op; visual mode excluded). Supersedes
  D147's "incremental downward movement deliberately does not resume following".
