  through **new narrow seams** — `Scaler`/`WithScaler`, `RolloutRestarter`/
  `WithRolloutRestarter` (`*kube.Clients` satisfies both) — so the tui package still
  constructs no client and a model without the seam is action-inert (no modal opens).
  Both stash their target in **one shared `mutateRes`/`mutateRef`** pair (only one modal
  up at a time) rather than a pair each. Added **`routeModalPromptKey`** (the modal
  twin of `routeFilterKey`/`routePickerKey`): while `modal.Prompting()` a no-text mapped
  key (enter/esc) is a control Action to `handleModalAction`, everything else is text to
  `modal.UpdatePrompt` — so digits type into the field, no raw key matched (D11); a
  confirm-mode modal is not Prompting and still routes through the sequencer (delete's
  D115 path, unchanged). A blank/non-integer/negative replica entry degrades to a
  status-bar error toast and runs nothing. Result messages `scaleDoneMsg`/`restartDoneMsg`
  → `handleScaleDone` ("scaled X to N" notice / error toast) and `handleRestartDone`
  ("restarted X" notice / error toast); the affected row updates via the live watch
  stream, not by hand. Launcher wires both seams (`run.go`). → D117.
