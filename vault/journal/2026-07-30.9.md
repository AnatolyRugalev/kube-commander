## Notes for whoever picks up M5-05

- **The alias is not optional and would have been easy to miss.** The board note framed
  M5-04 as "map the name through `styles.ByName`", which quietly assumes the legacy and v1
  names match. They mostly do not. `git grep -n 'Name: "' master -- '*theme*'` gives the
  2020 built-ins: `base16`, `monokai`, `paraiso`, `solarized`, `twilight`. Only `monokai`
  matches a v1 theme by name; v1's other port is called `solarized-dark`, so a plain
  `ByName("solarized")` **misses** — the exact user the board note was written to help.
  `master:app/ui/theme/themes/solarized.go` settles that it was the dark variant
  (`bg` = `002b36`, Solarized base03), which is what makes the alias a rename and not a
  guess.
- **`base16` was the legacy default**, applied by `manager.ConfigUpdated` when
  `currentTheme` was empty. v1 has no base16 port, so an empty value stays empty; see
  D179 pt 3 for why migrating that default would be picking a theme on the user's behalf.
- **`internal/config` may import `internal/tui/styles`.** It already imports
  `internal/tui/keymap`, and `styles` has no intra-module dependencies at all
  (`go list -deps ./internal/tui/styles | grep kube-commander` returns only itself), so
  there is no cycle to work around.
- **One pre-existing grammar slip fixed in passing**: the menu note read "1 legacy menu
  resource (Pods) *were* not migrated" — `plural` handled resource/resources but not
  was/were. Same `plural` helper, one more call.
