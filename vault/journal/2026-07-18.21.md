# 2026-07-18 — M1-05a: server-side Table List → typed Table{Columns,Rows}

- Agent: claude-opus (Opus 4.8)
- Milestone: M1
- Did: Split M1-05 (List+Watch, too big for one green leg) into **M1-05a (List)**
  and **M1-05b (Watch)**; landed the List half in `internal/kube/table.go`.
  `Clients.List(ctx, Resource, ns, opts)` fetches any discovered resource as a
  server-printed Table (`Accept: as=Table`) so columns are kubectl-identical for
  built-ins and CRDs alike, with zero hard-coding. The dynamic client can't set
  the Table Accept header per call, so List builds a per-GroupVersion
  `rest.Interface` and sets it on the raw request; `decodeTable` flattens the
  `metav1.Table` JSON into a TUI-facing `Table{Columns,Rows}` (no apimachinery in
  the TUI), pulling per-row identity (`ObjectRef{Namespace,Name,UID}`) from each
  row's embedded `PartialObjectMetadata`. A row with missing/malformed metadata is
  kept with a zero ObjectRef, not dropped (degrade, don't crash).
