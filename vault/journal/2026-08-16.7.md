# 2026-08-16 — STORY-06m: `/` filters the focused pane — the menu's kinds, or the table's rows

- Agent: opencode (do-rewrite-leg, interactive session)
- Milestone: M5 (UX-validation line, D268)
- Did: Folded in `2026-08-15-resources-pane-filter.md`, the S02 dead end that
  `/` in the resources pane aimed at the table instead of the pane's own kind
  list. **`app.filter` (`/`) now targets whichever pane holds focus**, fixed when
  the field opens (`app.menuFilter`): with the menu focused it opens over the
  menu (seeded from `menu.Filter()`), typing narrows the kinds there, and esc/enter
  behave exactly as the table filter's; with the table focused it keeps its M2-09b
  meaning. **The menu gained the table's full/displayed split**: authoritative
  `full` (seed + extras + discovery) beside a displayed `items` view, with
  `SetFilter`/`Filter`/`ClearFilter` and the three mutators (`Reconcile`,
  `addExtras`/`AddPinned`, `Unpin`) writing `full` and re-deriving `items` via
  `applyFilter`, so a narrowing filter never loses a kind (clear restores every
  row) and a discovery pass lands inside the pane's view. The filter matches the
  **D203 alias surface** — title, Kind, plural resource, short names, API group —
  so `deploy` finds Deployments and a CRD's short name finds it. `menu.Items()`
  keeps returning the authoritative `full` set, so the shell's kind inventory
  (cluster-search fan-out, the `:resource `/`:pin ` stages, pane memory) never
  shrinks when the pane is narrowed. Selection is preserved by GVR across a filter
  change (`restoreSelection`, the same resolve Reconcile uses); the not-found case
  (the selection's kind filtered out, or Unpin removed its own row) clamps rather
  than floating. `HelpMenu`'s hint set now advertises `/`; the open field's hint
  context is the shared filter context either way (its no-text keys act the same
  over both panes). Feedback file deleted (D69).
- Decisions: **D277** — `/` is pane-scoped (menu kinds or table rows, target fixed
  at open); the menu filter matches the D203 alias surface; `menu.Items()` stays
  the authoritative full list so a narrowed pane never shrinks search/pickers.
