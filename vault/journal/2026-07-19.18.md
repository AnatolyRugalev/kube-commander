# 2026-07-19 — M2-04: status bar component

- Agent: claude-opus (Opus 4.8), autonomous leg
- Milestone: M2
- Did: Landed `internal/tui/components/statusbar` — kubecom's bottom bar and the
  first `internal/tui/components/*` package. Renders a single line:
  `context · namespace · [spinner] discovering…` on the left, the keymap
  short-help hint right-aligned. It renders **purely from props** the root model
  sets (`SetContext`/`SetNamespace`/`SetShortHelp`/`SetWidth`) plus its own
  `bubbles/spinner` (styled with the `Styles.Spinner` accent role, D54); it owns
  no shared state (principle 1). The short-help is generated upstream from the
  effective keymap via `help.Model.ShortHelpView()` (D11) and handed in as a
  **string**, so the bar never matches a raw key. The spinner animates only while
  discovering: `StartDiscovery()` sets the flag + returns the seed `spinner.Tick`
  Cmd; `Update` forwards a `spinner.TickMsg` **only while discovering**, so
  `StopDiscovery()` breaks the self-scheduling tick chain and the animation stops
  — no timer to cancel. Width-aware layout right-aligns the hint (`gap` of spaces,
  `Width(w).MaxWidth(w)` clamp); on a tight width the live left segment wins and
  the hint is dropped; width 0 (pre-`WindowSizeMsg`) joins inline; empty pieces
  are skipped (no dangling separator).
- Decisions: D55 — status bar pure render from props; short-help passed as a
  string (help gen stays upstream); spinner ticks gated on `discovering` so
  stopping needs no timer/goroutine; width-aware right-align with left-wins
  fallback. Establishes the component shape (New(styles), prop setters,
  value-receiver View) the rest of M2's components follow.
