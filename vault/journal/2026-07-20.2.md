  `internal/tui/components/table` — folds a live watch delta onto the M2-06a
  snapshot, **preserving the selection by object UID**. RESET replaces
  columns+rows; ADDED/MODIFIED upsert a row keyed by `ObjectRef.UID` (unknown UID →
  appended, matching a server modify of an object that entered scope pre-sync);
  DELETED removes the matching row. The selected UID is captured before the delta
  and re-resolved after; if the selected row is gone the cursor keeps its index
  (clamped) rather than jumping to the top (delete-selected lands on the next row).
  RESET preserves selection too, because the watch layer emits RESET on every
  reconnect — keeping the cursor put through a transient reconnect (falls back to
  row 0 only when the object is gone). `computeColumns` reruns each delta (a wider
  cell widens its column) and `clampOffset` re-scrolls to keep the selection
  visible. An empty UID never matches (a degraded, metadata-less row can't be
  identified — principle 3). ERROR never reaches here (the M2-02 pump bridges it to
  an ErrorMsg); unknown event types are ignored. `SetTable` kept as the deliberate
  reset entry point (fresh List for a newly selected resource starts at the top).
