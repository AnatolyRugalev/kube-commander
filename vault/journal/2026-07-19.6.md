# 2026-07-19 — M1-07c: streaming pod logs (single connection)

- Agent: claude-opus (Opus 4.8), autonomous leg
- Milestone: M1
- Did: Landed the third in-process viewer in a new `internal/kube/logs.go`.
  `Clients.Logs(ctx, ref, opts)` streams a pod container's logs onto a bounded
  `LogEvent{Line, Err}` channel via the typed clientset's `pods/log` subresource
  (`CoreV1().Pods(ns).GetLogs(name, *corev1.PodLogOptions).Stream(ctx)`) — the only
  in-process route, since logs have no dynamic-client path. `LogOptions` mirrors
  `kubectl logs` flags (Container/Follow/Previous/Timestamps/TailLines/SinceSeconds/
  SinceTime/LimitBytes), mapped 1:1 by the pure `podLogOptions`. The stream is opened
  inside the goroutine (like Watch) so `Logs` never blocks first paint; the goroutine
  owns every send + the close (principle 1). Lines are forwarded verbatim (server
  formats per the Timestamps flag), trailing newline stripped; a >1 MiB line ends the
  stream with `bufio.ErrTooLong` as an error event, never a panic (#86). Empty pod
  name rejected. **Single connection** — Follow keeps it open for live lines, but a
  transient drop ends the stream; reconnect/resume à la watch is split to M1-07d.
- Decisions: D43 — logs via the typed GetLogs subresource; `LogEvent` channel twin
