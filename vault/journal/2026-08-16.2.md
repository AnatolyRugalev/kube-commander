# 2026-08-16 — STORY-06d: pickers open in navigation mode — j/k navigate, `/` opens the filter, the current choice is preselected

- Agent: opencode (do-rewrite-leg, interactive session)
- Milestone: M5 (UX-validation line, D268)
- Did: Flipped the picker's default open state. A picker's `Show()` now opens in
  **navigation mode** — list focused, j/k move the cursor, and the filter stays
  closed until `/` (ActionFilter) opens it. The S01 walk's sharpest dead end was a
  picker whose filter swallowed every letter: 4 dead `j`s in the namespace
  switcher, invisible to `keys analyze` (the analyzer fix is 06e's). The command
  palette's verb list is the one surface that keeps type-to-filter — it opens via
  `ShowFiltered` (field open on show), because its identity is "one place you type
  to make anything happen" (D197) and the S04 walk gave it a clean bill. The
  palette's argument stages (`:namespace `, `:context `, `:resource `, `:theme `,
  `:action `, `:pin `) open in navigation mode like every value picker (container,
  port). `OpenFilter`/`CloseFilter` are the in-place transitions between the two
  modes as the palette moves verb → argument stage → verb list; backspace-rewind
  still unwinds a navigation-mode stage (routePickerKey routes it there), and esc
  on a navigation-mode picker closes a `/`-opened filter before cancelling.
  **Preselection**: a value picker lands its cursor on the current choice —
  namespace stage on the current workspace (or the all-namespaces sentinel when
  scope is empty), context stage on the shell's current context, theme stage on
  the theme rendering now — via `picker.SelectValue`, applied after seeding
  (async stages preselect when their values land via `fillPaletteArg`). The
  `WithOptInFilter` construction option and the `optInFilter`/`filterOnShow`
  machinery were removed with it: the mode follows the surface's identity, not the
  picker's kind. `picker.New` no longer takes options. Help comments, hint-test
  reachability, and the README updated (pickers open in navigation mode; `/`
  narrows). Feedback `2026-08-15-picker-navigation-mode.md` deleted (D69).
- Decisions: **D272** — pickers open in navigation mode (list focused, j/k
  navigate, `/` opens the filter), the palette verb list is the one type-to-filter
  surface left, a value picker preselects the current choice, and the port
  picker's old opt-in construction is gone because navigation mode is now the
  default for it too. Supersedes D194 pt 2 for value pickers; D194 pt 1 (one fuzzy
  matcher) stands.
