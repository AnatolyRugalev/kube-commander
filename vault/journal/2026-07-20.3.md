# 2026-07-20 — M2-06c: table component (horizontal scroll)

- Agent: claude-opus (Opus 4.8), autonomous leg

- Did: Added horizontal scroll to `internal/tui/components/table` for tables wider
  than their pane — previously the right edge was just clipped (D58). One `hoffset`
  (in display columns) windows the whole block: header and every data row are padded
  to the same content width, so a single offset windows them identically and columns
  stay **aligned** across the scroll. `hclip` replaces `truncate` (returns runes
  `[hoffset, hoffset+innerW)`; the lipgloss style pads a short window back out — the
  no-wrap invariant D58 is preserved and its guard test still passes). `Update`
  handles `nav.left`/`nav.right` (`h`/`l`) **before** the empty-rows guard, so a
  header-only table scrolls too. **Scroll snaps to column starts** — `scrollRight`
  advances `hoffset` to the next visible column's start (leftmost hidden column
  becomes flush-left), `scrollLeft` retreats to the previous start or 0; a final
  column wider than the pane is still reachable via a `maxHOffset` fallback. Offset
  kept valid: `SetTable` resets it to 0 (fresh resource, mirroring the vertical
  reset-to-top), `SetSize`/`ApplyEvent` re-clamp via `clampHOffset`. Exposed
  `HOffset()` for tests and M2-07b's future pane-focus-vs-scroll arbitration.
  Completes the M2-06 table trio (06a snapshot / 06b deltas / 06c hscroll).
