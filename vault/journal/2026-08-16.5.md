  **The feature:** a new `app.unhealthy` action, default key `H` (shift+h — the
  feedback's own "healthy vs h"), narrows the current resource table to the rows
  the M4-06 cell classifier reads as unhealthy. The row predicate is the existing
  classifier lifted from cell to row (`table.rowUnhealthy`: any visible cell
  classifies to warn or error), so the "what's broken" view and the coloring tell
  exactly the same story. It composes with the `/` substring filter (both narrow;
  a row must survive both), resets on a new resource (`SetTable`), and `esc` clears
  it alongside the substring filter ("show me everything again"). The status bar
  shows an `unhealthy` marker while the view is on (so a narrowed-to-zero table
  never reads as empty), the palette lists the verb, the table hint carries it
  (`HelpTable`), and the keybindings doc regenerated. Wired: `keymap.go` (action,
  meta, binding), `table.go` (SetUnhealthyOnly/UnhealthyOnly, applyFilter,
  SetTable reset), `color.go` (rowUnhealthy), `app.go` (toggleUnhealthy, esc arm,
  syncFilterStatus marker), `statusbar.go` (SetUnhealthy marker), `palette.go`
  (verb). The action description is "Unhealthy only" — short enough to keep the
  help overlay's `app` column inside the 74-col inner budget at an 80-col screen,
  which the `?` overlay test pins (a longer phrase silently drops the whole column).
  Feedback `2026-08-15-unhealthy-workloads-quick-access.md` deleted (D69).
