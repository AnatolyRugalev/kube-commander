# 2026-07-22 — FB-nav-resource-palette: command-palette resource switch

- Agent: claude-opus-4-8
- Milestone: M2
- Did: Built the pane-free resource command palette (D96 slice 2, the counterpart to
  D99's toggleable menu). New registry action `resources.switch` (default `:`,
  rebindable — D11) opens a modal list of every browsable resource kind; `/` filters
  by substring and Enter switches the table to the chosen kind. Reused the generic
  picker component (D65): a second `picker.Model` (`resPicker`, `picker.New(s,
  "resource")`) that floats over the base browse view via `overlayCenter` (D95). The
  source list is `menu.Items()` filtered to available `ItemResource` rows — so
  discovered CRDs and per-context extras (D83) are included, the namespace seam and
  unavailable rows skipped — snapshotted with a rebuilt-on-open `resByLabel
  map[string]kube.Resource` (the picker is string-generic, so this maps the picked
  title back to its resource). Selecting drives the same `selectResource` path a menu
  drill-in takes (start the watch, `menu.SetActive`, focus the table), so it works
  with the menu hidden — closing the gap D99 flagged. Both pickers emit the shared
  `picker.SelectedMsg`/`CancelledMsg`, so the root branches on `msg.Kind ==
  resourcePickerKind` ("resource") to route; an empty Kind stays the namespace path,
  leaving the hermetic namespace tests unchanged. Key routing, `overlayActive`,
  `resize` sizing, and `View` overlay compositing all generalized to a new
  `activePicker()` accessor (at most one picker is open at a time). Watch-inert
  without `WithWatcher` → the palette does not open. → D100.
- Decisions: D100 — resource palette reuses the generic picker keyed by a distinct
  Kind (route on `msg.Kind`); source list is the menu's available resource rows via
  a rebuilt-on-open `resByLabel`; selecting drives `selectResource`; routing goes
  through `activePicker()`. FB-nav-menu-popup may fold the menu into this palette,
  superseding D99's fixed-pane half while keeping the Kind-routing + selectResource
