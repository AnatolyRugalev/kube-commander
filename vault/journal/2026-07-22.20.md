- Did: Landed the shared read-only viewer that every M3 viewer (YAML/describe/logs/
  secret) will feed content into, instead of each rolling its own pager. New package
  `internal/tui/components/viewer`: a `Model` wrapping `charm.land/bubbles/v2/viewport`,
  Kind-stamped like the picker (D56). `SetContent(text)` sets the text and resets
  scroll to the top; `SetSize(w,h)` sizes a centered bordered box (screen minus a
  4-cell margin, floored) and the inner viewport. `Update(a keymap.Action)` drives

  bottom (GotoTop/Bottom = gg/G), half/full page — and nav.back emits `ClosedMsg{Kind}`;
  the viewport never receives a raw KeyMsg and its mouse-wheel is disabled, so no
  hard-coded key leaks in (D11). `View()` returns a **bare** box (title bar + viewport)
  the root will composite via `overlayCenter` (D95) — never replacing the base. Title
  clips to the box width. `AtBottom()` exposed for the M3-06 follow-logs auto-scroll.
  Component-only and hermetic — no app wiring (a viewer isn't reachable until M3-02).
