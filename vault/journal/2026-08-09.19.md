# 2026-08-09 — MONO-03: the browse filter seam leaves `app.go` as `components/filter`

- Agent: deepseek-v4-flash (do-rewrite-leg)
- Milestone: none (standing board item filed by D264)
- Did: The third MONO extraction (D264 pt 4) moved the M2-09b browse filter seam
  out of the `app.go` shell into a self-contained `components/filter` sub-model,
  following the D265 shape the board note named as the last candidate. The
  component owns the field's interaction state — the textinput (its value, cursor,
  focus) and the open flag — and exposes small verbs (`Open(initial)` + Focus cmd,
  `Commit`, `Reset`, `Active`, `Value`, `View`, `Update`) so the shell's filter
  routing is a thin delegation; the shell keeps the table (the authoritative rows)
  and performs the narrowing (`table.SetFilter` on every text update, plus
  `ClearFilter` on cancel). The two fields `filterInput`/`filtering` became one
  `filter filter.Model`; `openFilter`, `routeFilterKey`, `commitFilter`,
  `clearFilter`, `syncFilterStatus`, `overlayActive` and the help-context case
  delegate to it, and the two teardown points (fresh resource / context reset) call
  `Reset()`. The control/text routing (`routeFilterKey`) stays in the shell because
  it resolves against the shell's keymap, exactly as D265 pt 2's "routing lives in
  the shell" precedent. The component is style-free (it renders the plain
  textinput into the status bar), so it needs no `SetStyles`/`applyStyles`/
  `themeSurfaces` entry, the secretviewer precedent. Behavior is unchanged — the
  whole M2-09b surface (`TestFilterOpensAndNarrows`, commit/cancel/backspace tests,
  the teatest `TestProgramFilterFlow`, HINT-03's browse-filter hint test) passes
  against the delegated path, its assertions now reading `m.filter.Active()`/
  `m.filter.Value()`. Direct component tests added
  (`components/filter/filter_test.go`). **This closes the MONO line**: every seam
  D264 named (panel, entry list, browse filter) is extracted; the board note says
  so and a future leg re-opens it only when a new clean seam appears.
