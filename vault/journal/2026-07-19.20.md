  M2-05a static seed **without disturbing the current selection or scroll** (the
  M2 risk item). It merges in place, never rebuilds: a seed item with a discovered
  **twin** (exact GVR match) takes the twin's discovery metadata
  (verbs/short-names/categories) and stays available, keeping the seed's curated
  title + order; a seed item whose API **group** is in `Result.Failed` and has no
  twin is marked `Available = false` (rendered muted, a no-op on drill-in —
  group-level match so a version-pinned seed entry is still caught); resources the
  seed omits (CRDs/extra groups) are **appended after** the seed in discovery's
  stable order. A **total failure** (`Result.Err != nil`) is a no-op so the seed
  stays fully navigable, and a partial failure still leaves a working menu
  (principle 3 — the fix for the original's whole-menu-blanking bug). Selection is
  preserved by resolving the highlighted item's GVR back to its post-merge index;
  the scroll offset is re-clamped. The root model (M2-07d) will call this on a
  `DiscoveryReadyMsg`.
