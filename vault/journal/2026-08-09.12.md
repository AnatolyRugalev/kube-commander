# 2026-08-09 — THEME-07: the theme picker previews live as the cursor moves

- Agent: claude-opus (do-rewrite-leg)
- Milestone: none (feedback-driven — `2026-08-09-theme-picker-live-preview`)
- Did: The maintainer asked that "theme switching should happen as I change
  selection in the palette, so I can test the look without pressing enter."
  `routePickerKey` now runs a new `previewTheme` after every key that can move the
  palette's cursor while the `:theme ` stage is open — nav actions through
  `p.Update(action)` and filter narrowing through `p.UpdateFilter` both — so the
  whole screen, painted background included (`View` reads `Theme.Background` each
  frame, D249), re-themes to the row under the cursor. `enter` still commits
  through the untouched `applyThemeNamed` (notice + canvas probe + config
  write-back), and every way out without committing restores the theme that was
  rendering when the stage opened: `closePalette` (esc on a key-opened stage) and
  `showPaletteVerbs` (esc on a typed stage, backspace rewind) both call the new
  `restoreThemeAnchor`, which repaints back silently. The anchor is set in
  `enterPaletteArg`'s theme case. `applyThemeNamed` needed no change: its no-op
  check (`theme.Name == m.styles.Theme.Name`) reads correctly because the commit
  path's `closePalette` has just restored the anchor, so committing the anchor row
  after a preview tour still costs neither a repaint nor a file write. The marker
  deliberately stays on the anchor row during a preview — re-seeding `themeItems`
  to move it would reset the picker's cursor and fight the navigation. Six new
  tests in `theme_test.go` walk repaint-on-move, silent preview (no cmd), typing
  narrowing, commit-persists-after-preview, commit-of-anchor no-op, and both
  cancel/rewind restore paths. `docs/configuration.md`'s theme paragraph now names
  the live preview. Feedback file deleted.
- Decisions: D260 (preview is repaint only — no notice/probe/persist on cursor
  move; a cancel is a restore, silent; the marker does not follow the preview;
  committing the anchor row stays a no-op).
