  Three edits. **table**: the M4-06 cell classifier is exported for surfaces that are
  not tables — `table.Role` (None < Success < Warn < Error) and
  `table.ClassifyValue(column, value)`, a one-line wrapper over the existing
  `classifyCell`. A describe dump is text, not rows, so it cannot go through
  `UnhealthyCells` as the board note assumed; what it must not do is grow a *second*
  vocabulary, which is the whole point of the export. `"warning"` joins `statusWords`
  as a warn word (an event of type Warning is a warning by definition, and any printer
  that names the state outright means it).
  **viewer**: a new `PaintDescribe(styles, text) string`, pure text→text. Three line
  shapes — `Key:` alone is a section heading (accented), `Key:  value` mutes the key
  and paints the value with the role the classifier reads under the column that key
  speaks for (`describeKeyColumns`: Reason/Last State → STATUS, Restart Count →
  RESTARTS, …), and anything else is a whitespace-aligned Conditions/Events row whose
  fields are classified one by one. Two restraints carry most of the value. Painting is
  **opt-in per key**: a key not in the map leaves its value plain, which is what stops
  an annotation's `sidecar.istio.io/inject: false` from being painted as a failed
  condition (the false-positive that killed the "classify every token" version). And in
  the column rows only **warn-or-worse** is painted — a dump is mostly fine, and
  colouring the fine parts is what buries the broken one, so `Ready False` is red while
  `Initialized True` is left alone. `describeField` rejects a candidate key holding a
  double space or longer than 40 runes, so `Warning  Unhealthy  1m  kubelet  Liveness
  probe failed: connection refused` is read as a row, not as a field with a 60-character
  key — kubectl separates aligned columns by two or more spaces, which is the only
  signal available. `SetDescribeContent` keeps the raw dump beside the painted content
  so `SetStyles` repaints in place (same scroll offset — a restyle is not a reopen);
  `SetContent` clears it, so plain content keeps the old colours-only contract.
  **shell**: `handleDescribeLoaded` seeds through `SetDescribeContent`; no styled string
  crosses the shell boundary.
