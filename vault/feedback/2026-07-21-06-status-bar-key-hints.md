# Show main key hints at the bottom

- Submitted: 2026-07-21
- Priority: normal
- Area: status bar / key hints

Would be nice to have the **main key hints along the bottom** of the screen —
a persistent one-line hint bar showing the most relevant keys for the current
context (e.g. navigation, `/` filter, `ctrl+n` namespace, `?` help, `q` quit),
updating with focus/context. The welcome page already generates registry-based
key hints; extend that idea to a persistent bottom hint bar during browsing.
