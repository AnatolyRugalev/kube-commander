# Command palette should show name + description in two columns

- Submitted: 2026-08-06
- Priority: normal
- Area: command palette

The palette dropdown currently shows only the description text for each
entry. That's annoying — I want to see the command name too, not just its
description. Lay the dropdown out as two columns: command name, then
description, so both are visible at a glance without one crowding out the
other.
