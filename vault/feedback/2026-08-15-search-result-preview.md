# Search result preview — see the hit before committing to it

- Submitted: 2026-08-15
- Priority: high
- Area: cluster search (walked during S05)

Navigating search results I opened the wrong hit and had to search again. I want a
**preview** of the highlighted result inside the search view — the hit's name /
namespace / kind / a snippet — so I can pick the right row *before* closing
search, and not spend a whole re-search on a wrong guess.

Shape for the fold-in: a preview pane or line for the cursor's hit (reuse
whatever describe/logs already render), shown while the result is highlighted.
The S05 story's "did the results tell you enough to pick the right one without
opening each" is exactly this question — today the answer was no.
