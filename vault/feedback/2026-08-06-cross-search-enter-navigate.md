# Cross-resource search: Enter should hand off from typing to hjkl navigation

- Submitted: 2026-08-06
- Priority: normal
- Area: cross-resource search (SEARCH)

In cross-resource search, once I've typed a query and hit `Enter`, I want
typing to stop being captured by the search input and control to switch to
normal navigation (`hjkl`/arrows) over the results — right now (assuming
this isn't already the case) keys keep going to the query input instead of
letting me move through matches. `Enter` should be the seam: query editing
before it, result navigation after it.
