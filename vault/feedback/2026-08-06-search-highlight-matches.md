# Search should highlight matches

- Submitted: 2026-08-06
- Priority: normal
- Area: search — both in-panel `/` search and cross-resource search

Both regular (in-panel `/`) search and cross-resource search should
visually highlight the matched text in results, if that isn't already
happening. Check current behavior for both before doing the work — this may
already be partially done for one and not the other.
